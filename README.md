# 🎞️ Image Slider using JavaScript

A simple and beginner-friendly **Image Slider** created using **HTML, CSS, and JavaScript**.

This project demonstrates how JavaScript can be used to change images dynamically when the user clicks the slider buttons.

## 🚀 Features

* Simple and clean image slider
* Previous and Next buttons
* Images change dynamically using JavaScript
* Beginner-friendly code
* Responsive design
* Easy to understand and customize

## 🛠️ Technologies Used

* **HTML5** – For creating the structure
* **CSS3** – For styling the slider
* **JavaScript** – For slider functionality

## 📁 Project Structure

```text
Silder-js/
│
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

1. The HTML file creates the image slider structure.
2. CSS is used to design and style the slider.
3. JavaScript stores the images and changes the displayed image when the user clicks the buttons.
4. The slider moves between the images using the Previous and Next buttons.

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/parmarnamrataba10/Silder-js.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

That's it! 🎉
